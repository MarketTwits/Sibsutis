    Задание на практику

    Задания по ознакомительной практике для студентов дистанционной формы обучения направления 09.03.01 «Информатика и вычислительная техника» профиль «Программное обеспечение средств вычислительной техники и автоматизированных систем»

    Отчет по ознакомительной практике должен содержать:

    • Формальная часть проекта (запелнены все формы с учетом пояснений)
    • Условие задачи
    • Описание используемого алгоритма
    • Листинг программы
    • Результаты тестирования (не менее 4-х тестов)

    Кроме отчета на проверку присылается файл с кодом программы и набором тестов. Программу можно писать на любом языке программирования.


    Номер варианта выбирается по последней цифре пароля студента

    0.

    Написать программу, реализующую операции над числами в восьмеричной системе счисления: сложение, вычитание, перевод в десятичную систему счисления. Вид операции должен выбираться из меню. Предусмотреть циклический выбор операций во время одного запуска программы.

    1.

    Написать программу, находящую все варианты разбиений натурального числа n на слагаемые. Входные данные: n. Выходные данные: все упорядоченные варианты разбиений числа n на слагаемые.

    2.

    Написать программу, реализующую операции над числами в четверичной системе счисления: сложение, вычитание, перевод в десятичную систему счисления. Вид операции должен выбираться из меню. Предусмотреть циклический выбор операций во время одного запуска программы.

    3.

    Написать программу, генерирующую для числового множества из n элементов сочетания по m элементов. Входные данные: n, m, множество. Выходные данные: все упорядоченные сочетания.

    4.

    Написать программу, реализующую операции над числами в шестеричной системе счисления: сложение, вычитание, перевод в десятичную систему счисления. Вид операции должен выбираться из меню. Предусмотреть циклический выбор операций во время одного запуска программы.

    5.

    Написать программу, генерирующую для числового множества из n элементов размещения по m элементов. Входные данные: n, m, множество. Выходные данные: все размещения.

    6.

    Написать программу, находящую диаметр связного невзвешенного неориентированного графа, т.е. максимум расстояний между всевозможными парами его вершин. Расстояние между двумя вершинами – кратчайший путь из одной вершины в другую. Граф задается матрицей смежностей.

    7.

    Написать программу, реализующую операции над числами в шестнадцатеричной системе счисления: сложение, вычитание, перевод в десятичную систему счисления. Вид операции должен выбираться из меню. Предусмотреть циклический выбор операций во время одного запуска программы.

    8.

    Найдите все вершины невзвешенного ориентированного графа, достижимые из указанной вершины. Каждая вершина должна выводиться один раз. Граф задается матрицей смежностей.

    9.

    Найдите все вершины взвешенного неориентированного графа, к которым существует путь заданной длины от указанной вершины. Каждая вершина должна выводиться один раз.
